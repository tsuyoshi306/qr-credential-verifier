# 機能仕様 11: 読み取りデータのCSV出力

## US-24: 履歴のCSVエクスポート
- 履歴タブに「CSV出力」ボタンを設け、読み取り済みデータをCSVでダウンロードできる
- 公式検証済みか否か、公式判定、証明書情報などのカラムを含む
- Excel（日本語）で文字化けしないよう UTF-8 BOM 付きで出力

## カラム定義
| 列 | 内容 | 取得元 |
|----|------|--------|
| スキャン日時 | scannedAt | 履歴 |
| 資格名 | CN | qrData再解析 |
| 氏名 | UN | qrData再解析 |
| 生年月日 | UB | qrData再解析 |
| 登録番号 | RN | qrData再解析 |
| 登録年月日 | RD | qrData再解析 |
| 発行年月日 | ID | qrData再解析 |
| 交付機関 | IA | qrData再解析 |
| 交付者名 | IN | qrData再解析 |
| 署名検証 | sigStatus（OK/NG/スキップ/エラー） | 履歴 |
| 公式検証済み | はい/いいえ | officialValid!=null |
| 公式判定 | 有効/無効/—（resultText） | 履歴 |
| 確認日時 | officialCheckedAt | 履歴 |
| 証明書_所有者別名 | 所有者別名 | 公式検証時に保存 |
| 証明書_発行者別名 | 発行者別名 | 公式検証時に保存 |
| 証明書_シリアル番号 | シリアル番号 | 公式検証時に保存 |
| 証明書_有効期間 | 有効期間 | 公式検証時に保存 |
| QR_URL | qrData | 履歴 |

## 受入条件
- [ ] 履歴タブに「CSV出力」ボタン（履歴が空のときは非表示/無効）
- [ ] 全履歴を上記カラムでCSV化しダウンロード（ファイル名に日付）
- [ ] 公式検証済みか否か・判定・証明書情報のカラムがある
- [ ] UTF-8 BOM付きでExcelで文字化けしない
- [ ] CSVエスケープ（カンマ・引用符・改行）が正しい
- [ ] 公式検証していない行は証明書列が空・「公式検証済み=いいえ」
- [ ] 公式検証時に証明書情報を履歴へ保存（CSVで出せるように）

## 技術
- 公式検証成功時に `certOwner/certIssuer/certSerial/certValidity/officialCheckedAt` を
  `updateScan` で保存（証明書テーブル先頭=リーフ証明書から抽出）
- QR登録情報の各列は `analyzeCredential(qrData)` を再実行して取得（ネット不要）
- 生成は純粋関数 `buildCsv(rows)` とし、フロントで Blob ダウンロード
