# 機能仕様 07: ファイル一括アップロード

## 背景
複数の資格者証（PDF/画像）をまとめて確認したいニーズ。1ファイルずつでは手間。

## US-17: 複数ファイルの一括取り込み
- ファイル選択で複数のPDF/画像を選べる
- 各ファイルからQRをデコードし、登録情報を解析、履歴に保存する
- 一覧（バルク結果）で各ファイルの結果を表示する

## US-18: 一括での公式検証
- バルク結果の各行で個別に「公式検証」できる
- 「全件まとめて公式検証」ボタンで順次照会できる（サイト負荷に配慮し直列実行）

## 受入条件
- [ ] file input が複数選択（multiple）に対応
- [ ] 1ファイルのみ/カメラのときは従来の単一結果カード表示
- [ ] 複数選択時はバルク結果リストを表示（単一カードは隠す）
- [ ] 各行: ファイル名・資格名/氏名・署名ステータス・QR無し等のエラー
- [ ] 各行で個別の「🏛 公式検証」が可能（✅有効/⛔無効/エラーを行内表示）
- [ ] 「全件公式検証」で直列に順次実行、進捗が分かる
- [ ] すべて履歴に保存（公式検証結果も反映）
- [ ] 大量選択でもUIがフリーズしない（逐次処理・件数表示）

## 技術
- `readQrFromFile` を各ファイルに適用（既存）
- `analyzeCredential` で解析、`addScan`/`updateScan` で履歴反映（既存）
- 公式検証のfetchを共通関数 `requestOfficialVerification(checkdata)` に抽出し、
  単一・バルク両方から再利用

## スコープ外
- 並列大量リクエスト（直列のみ）
- ZIP等のアーカイブ展開
