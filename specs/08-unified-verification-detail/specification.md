# 機能仕様 08: 単一/一括 検証結果の表示統一と「詳細」展開

## 背景
一括検証の各行が公式検証の全詳細を即表示すると一覧が長くなる。一方で単一検証と
一括検証で表示項目が食い違うのは混乱を招く。両者の表示内容を完全一致させつつ、
一括ではコンパクト表示＋「詳細」展開とする。

## US-19: 表示項目の統一
- 公式検証の詳細表示（判定・確認日時・登録情報・証明書情報）は、
  単一検証と一括検証で**同一の項目・同一のレンダリング**であること
- 実装上は共通関数 `buildOfficialResultHtml(data)` を唯一の真実とする

## US-20: 一括は「詳細」展開
- 一括の各行は既定で**コンパクト表示**（判定バッジ：✅有効／⛔無効＋確認日時程度）
- 各行に「詳細」ボタンを置き、押下で単一検証と同一の詳細を展開（再押下で折りたたみ）
- 「全件公式検証」実行後も各行はコンパクト＋「詳細」展開で統一

## 受入条件
- [ ] 単一検証の詳細と一括「詳細」展開の内容が一致（同じ関数で生成）
- [ ] 一括各行は既定でコンパクト（判定のみ）、「詳細」ボタンで全詳細を開閉
- [ ] 詳細未取得（未検証）の行には「詳細」ボタンを出さない
- [ ] 無効/エラー時もコンパクト表示＋詳細展開が成立
- [ ] 既存のビルド・テストが通る

## スコープ外
- 単一検証側のレイアウト変更（現状維持。詳細は従来どおり直接表示）
