# 機能仕様 09: 一括の技術情報表示 と 履歴詳細の再検証

## US-21: 一括「詳細」にも技術情報
- 単一検証の「🔧 技術情報を表示」（署名検証バッジ＋QR生データURL＋注意書き）を、
  一括の各行「詳細」内にも同一表示する
- 実装は共通関数で生成し単一と一致させる

### 受入条件
- [ ] 一括「詳細」内に「🔧 技術情報を表示」（折りたたみ）がある
- [ ] 内容（署名バッジ・生URL・注意書き）が単一検証と同一生成

## US-22: 履歴の行から再表示・再検証
- 履歴タブの各行を押下すると、その資格者証の**読み取り結果を再表示**する
  （単一検証の結果カード：登録情報＋技術情報＋公式検証ボタン）
- 結果カードの「公式検証」押下で**再度デジタル庁検証サイトに照会**し、
  単一検証と同一の結果表示を行う
- 履歴からの再表示では新規履歴を増やさず、公式判定は既存レコードを更新する

### 受入条件
- [ ] 履歴行（削除ボタン以外の領域）押下でスキャン画面の結果カードに再表示
- [ ] 保存済み `qrData` から再解析して登録情報・技術情報を表示
- [ ] 「公式検証」で再照会し単一と同一表示、結果は当該履歴レコードを更新
- [ ] 履歴からの閲覧で履歴件数が増えない（addScanしない）
- [ ] 削除ボタンは行表示と独立して動作（イベント伝播を止める）

## 技術
- `buildSigBadgeHtml(analysis)` / `buildTechInfoHtml(url, analysis)` を共通化
- `showResult(url, {save, existingId})` で保存制御。履歴閲覧時 save=false, existingId=該当id
- 履歴行クリック→スキャンタブへ切替→`handleDetected(qrData, {save:false, existingId})`
