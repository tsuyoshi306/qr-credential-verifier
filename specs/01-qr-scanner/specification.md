# 機能仕様 01: QRコードスキャナー

## 要件定義

### ユーザーストーリー
- **US-01**: ユーザーとして、スマホのカメラでQRコードをスキャンし、デジタル資格者証のデータを取得したい
- **US-02**: ユーザーとして、スキャン結果（URL）をすぐに確認し、検証サイトへ遷移したい
- **US-03**: ユーザーとして、スキャン中はファインダー（カメラ映像）を画面で確認したい

### 受入条件
- [ ] スマホブラウザでカメラが起動し、QRコードを認識できる
- [ ] QRコードを検出した時点でスキャンが自動停止する（手動シャッター不要）
- [ ] スキャン結果のURLが画面に表示される
- [ ] 「検証サイトで確認」ボタンをタップすると `https://dqcvs.nqs.go.jp/` へ遷移する（QRのURLをそのまま開く）
- [ ] カメラ権限を拒否した場合はエラーメッセージを表示する
- [ ] HTTPSまたはlocalhost環境でのみカメラが動作する（ブラウザ仕様）

## 技術仕様

### QRスキャン方式
- `getUserMedia({ video: { facingMode: 'environment' } })` でリアカメラを使用
- `<video>` 要素にストリームを描画し、`<canvas>` に毎フレームコピーして jsQR で解析
- jsQR が QRデータを返したら即座にストリームを停止

### 検証URL生成
- QRコードの内容が `https://dqcvs.nqs.go.jp/` から始まる場合: そのまま開く
- それ以外の場合: スキャン結果を表示し「このQRコードは資格者証ではありません」と警告

### エラーケース
| 状況 | 表示メッセージ |
|------|----------------|
| カメラ権限拒否 | 「カメラへのアクセスが許可されていません。ブラウザの設定を確認してください。」 |
| カメラ非対応ブラウザ | 「このブラウザはカメラ機能に対応していません。」 |
| QR読み取り失敗（10秒タイムアウト） | なし（継続スキャン、タイムアウトなし） |
