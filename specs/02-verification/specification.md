# 機能仕様 02: 検証連携

## 要件定義

### ユーザーストーリー
- **US-04**: ユーザーとして、スキャンしたQRのURLをデジタル庁の検証サイトで確認したい
- **US-05**: ユーザーとして、検証のたびにQRをスキャンし直さなくて済むよう、過去のスキャン結果からも検証サイトへ飛べるようにしたい

### 受入条件
- [ ] 「検証サイトで確認」ボタンをタップすると、QRコードのURLを新しいタブで開く
- [ ] 検証サイトURL（`dqcvs.nqs.go.jp` のドメイン）に遷移した場合、「検証済み」フラグをローカルストレージに記録する
- [ ] 検証済みのスキャン結果には「✓ 検証済み」バッジを表示する

## 技術仕様

### 検証フロー
```
QRスキャン完了
    ↓
QR内URLを表示
    ↓
ユーザーが「検証サイトで確認」をタップ
    ↓
新しいタブで dqcvs.nqs.go.jp を開く
    ↓
（タブを閉じてアプリに戻る）
    ↓
「検証しました」ボタンをタップ → verified フラグを IndexedDB に保存
```

### 注意事項
- デジタル庁検証サイトはサードパーティサイトのため、結果をプログラム的に取得することは不可
- 検証済みフラグはユーザーの自己申告ベースで記録する
