# 機能仕様 03: スキャン履歴・保管

## 要件定義

### ユーザーストーリー
- **US-06**: ユーザーとして、過去にスキャンしたQRコードの一覧を見たい
- **US-07**: ユーザーとして、スキャン結果をメモ付きで保存したい
- **US-08**: ユーザーとして、不要な履歴を削除したい

### 受入条件
- [ ] スキャンするたびに履歴に自動追加される（日時・QRデータ・検証フラグを保存）
- [ ] 履歴画面でスキャン一覧を新しい順に表示する
- [ ] 各履歴エントリから再度「検証サイトで確認」ができる
- [ ] 各履歴エントリを個別に削除できる
- [ ] 「全て削除」ボタンで全履歴を一括削除できる（確認ダイアログあり）
- [ ] ブラウザを閉じても履歴が保持される（IndexedDB）

## データスキーマ（IndexedDB）

```js
// DB名: qr-credential-verifier
// ストア名: scans

{
  id: string,          // UUID
  scannedAt: Date,     // スキャン日時
  qrData: string,      // QRコードの生データ（URL）
  isVerified: boolean, // 検証済みフラグ
  verifiedAt: Date | null, // 検証日時
  memo: string,        // ユーザーメモ（任意）
}
```

## UI仕様
- 履歴リストは `<ul>` + `<li>` のシンプルなリスト
- 各アイテム: 日時 / QRデータ（省略表示） / 検証済みバッジ / 「確認」「削除」ボタン
